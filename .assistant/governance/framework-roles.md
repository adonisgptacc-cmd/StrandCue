# Framework roles

- Superpowers: primary planning, implementation, TDD and review workflow.
- Accepted Phase 1 specification plus design/plan documents: specification/change layer. OpenSpec CLI is not required to interpret these existing documents.
- Supabase skill: current database/Auth documentation and checks.
- ECC security-review: specialist review; example web-cookie/logging code does not override native storage or StrandCue's stricter no-personal-data logs.
- Codex agents: independent bounded implementation/review within this task.

No gstack, GSD, BMAD, scanner, memory daemon or alternate methodology is installed by this adoption. Available host plugins are not automatically project dependencies. No technical enforcement claim is made for skill routing: it is advisory, with permissions and review at the action boundary.
